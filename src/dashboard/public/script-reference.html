Custom code gives an item or a trait real mechanics. You write a few small functions here; the bot runs them for every character the code applies to. No GitHub or bot files involved — save, and it is live.

1. When does my code run?

Attach the script in Arts & Traits (martial arts, cultivation methods, Qi Cores, special traits) or in Items → Custom code (weapons, pills). It then runs for a character who:

  • has the special trait;
  • knows the cultivation method, has the qi core, or knows the martial art (manual);
  • has the weapon equipped as main weapon;
  • is consuming the pill (pill scripts only run during that consumption).

Order when several apply: traits → cultivation methods → qi core → main weapon → martial arts → the pill. Each one receives the result of the previous one.

2. The shape of a script

A script assigns functions to hooks. Every hook is optional — write only the ones you need.

hooks.effects = (ctx, fx) => {          // the stat sheet
  if (ctx.character.impurity >= 50) fx.yieldMultiplier = 1;
  return fx;                             // always give fx back
};
hooks.qiGain = (ctx, amount) => amount;              // Qi received
hooks.breakthroughChance = (ctx, chance) => chance;  // Realm Breakthrough %
hooks.consume = (ctx, result) => result;             // a pill being consumed

Rules: plain JavaScript; each run has 150 ms; there is no internet, files or require; console.log doesn't exist — use fx.notes.push('text') or result.notes.push('text') to show text. Your code gets a copy of the data, so it can't break saved characters: only what you return is used. If a script errors, the bot ignores it and shows "Script error" on the sheet.

4. hooks.qiGain(ctx, amount) — how much Qi is received

Return the Qi actually gained. ctx.extra.source says where it came from: 'staff' (/give qi), 'points' (spending points into Qi) or 'pill'. The Qi hard cap is applied after your hook.

hooks.qiGain = (ctx, amount) => ctx.extra.source === 'pill' ? amount * 1.5 : amount;
5. hooks.breakthroughChance(ctx, chance) — Realm Breakthrough chance

chance = the realm's chance + pills already consumed. Return the new chance (it is kept between 0 and 100).

hooks.breakthroughChance = (ctx, chance) => ctx.character.impurity >= 50 ? chance - 10 : chance;
6. hooks.consume(ctx, result) — a pill is consumed

Runs after absorption, impurity reduction, tolerance and realm penalties are worked out, before anything is applied. ctx.extra.item = { id, name, element, pill }; ctx.extra.usesThisMonth = how many the character already took this month. Math.random() works for random effects.

// A Yang cultivation that hates Yin pills
hooks.consume = (ctx, result) => {
  if (result.element === 'Yin') {
    result.impurity *= 2;
    result.notes.push('☯️ Your Yang meridians reject the Yin energy — impurity doubled.');
  }
  return result;
};

8. World hooks — regions, factions, treaties, events, diplomacy, battles, shops

Attach a script to a region (Map → click → Edit), a faction (Politics), an event, a policy, a diplomacy action, a treaty / custom agreement or a formation. Use it for very specific deals and setups that the normal fields can't express.

World hooks get ctx.world (calendar), ctx.region (name, terrain, population, prosperity, security, unrest, corruption, fort, coffers, taxRate, controller, stock, prices, production, events, policies) and ctx.faction (id, name, kind, treasury, influence, reputation, members, regions, policies) where they apply.

// Custom agreement: "The Namgoong pay Mount Hua 40 Nyang a turn while Mount Hua guards their caravans"
hooks.treatyTick = (ctx, l) => {
  l.transfers.push({ from: 'namgoong-clan', to: 'mount-hua-sect', nyang: 40 });
  if (ctx.world.turn > ctx.treaty.startTurn + 112) l.end = true;   // four weeks of 6-hour turns
  return l;
};

// Region: Luoyang's great market — luxuries always sell, and the Lantern Festival is bigger here
hooks.regionTick = (ctx, m) => {
  m.demand.luxury = (m.demand.luxury || 1) * 1.3;
  if (ctx.region.events.includes('lantern-festival')) m.prosperity += 1;
  return m;
};

// Faction: the Beggar Sect's network of informants sells secrets — 10 Nyang a turn
hooks.factionTick = (ctx, l) => { l.treasury += 10; return l; };

// Faction (Shaolin's script): the monks never offer political marriages
hooks.diplomacy = (ctx, p) => {
  if (ctx.stage === 'propose' && ctx.kind === 'marriage') p.blocked = 'Shaolin monks do not marry.';
  return p;
};

// Army: the Plum Blossom banner — +1 die in melee, and the men never lose heart in Shaanxi
hooks.battleRound = (ctx, v) => {
  const me = ctx.side === 'attacker' ? v.attacker : ctx.side === 'defender' ? v.defender : null;
  if (!me) return v;
  if (ctx.phase === 'shock') me.dice += 1;
  if (ctx.region.province === '陕西') me.morale += 5;
  v.notes.push('The plum-blossom banner rises.');
  return v;
};
hooks.armyTick = (ctx, v) => { v.morale += 1; return v; };   // morale recovers faster every turn

// Region: mountain fog — the attacker fights half-blind in the fire phase
hooks.battleRound = (ctx, v) => { if (ctx.side === 'region' && ctx.phase === 'fire') v.attacker.damage *= 0.8; return v; };
9. Handy recipes 
// Weapon: +3 Strength only while Impurity is under 50
hooks.effects = (ctx, fx) => {
  if (ctx.character.impurity < 50) { fx.tempStats.strength += 3; fx.notes.push('🗡️ The blade hums: +3 Strength.'); }
  return fx;
};

// Trait: +1 Qi Bar for Wudang members
hooks.effects = (ctx, fx) => {
  if (ctx.character.sect === 'Wudang Sect') fx.qiBarBonus += 1;
  return fx;
};

// Core art: immune to the 75-impurity stat debuff
hooks.effects = (ctx, fx) => { fx.statMultiplier = 1; return fx; };

// Qi core: every pill gives 2 extra Qi (attach to a Qi Core in Arts & Traits)
hooks.consume = (ctx, result) => {
  if (result.yieldType === 'qi') result.yieldAmount += 2;
  return result;
};

// Cultivation: +10% breakthrough chance at Peak or above
hooks.breakthroughChance = (ctx, chance) => ctx.character.realmIndex >= 5 ? chance + 10 : chance;

Simple numbers don't need code: absorption rates, affinities and impurity reduction are fields in Arts & Traits; weapon stat bonuses and pill yields are fields in the item editor.
